# Excel

Excel is really widely used even in rocketry to visualize thrust curves from static test data and other calculations as well a huge number of uses in rocketry are as shown on [Nakka Rocketry](https://nakka-rocketry.net/) website and [Hall Cat Rocketry](https://www.halfcatrocketry.com/) uses it for their [halfcatsim](https://www.halfcatrocketry.com/halfcatsim) tool for simulation of nitrous oxide blowdown liquid bipropellant motors using a fuel piston.
